**gh** (GitHub) · `gh pr create`, `gh pr view`, `gh pr checks`, `gh issue list`, `gh run list`, `gh run view --log-failed`.
Corpo de PR e issue autossuficiente; cite o nó do Zeno quando houver.
Aprovar o próprio PR, mergear na principal, apagar repo ou release: passo da Entrega, de pessoa.
Conferir o login: só `zeno ferramentas` (o código de saída de `gh auth status`).
Nunca: `gh auth token`, `--show-token`, ler `~/.config/gh/` ou imprimir `GH_TOKEN`.
